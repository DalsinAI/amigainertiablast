# Inertia Blast for GFOS

Inertia Blast (Dennis Payne's GPL remake of Thrust) for GFOS: AmigaOS 3.2 with GFOpenUp, on a 68040/68060 with FPU, using GFOpenUp's SDL2.module and SDL2_mixer.module.

## Status

- Port is on `main` (PR #1 merged 16 Nov 2026).
- Built in Cradle's os32-gcc16-open6 stove; release archive produced.
- Lab run on 16 Nov: title, Mission 1, controls, crash/restart, quit. Sound not verified (lab muted).

See `AMIGA_PORT.md` for build, install and controls.

Designed, tested and delivered by The AmiCradle Team.
